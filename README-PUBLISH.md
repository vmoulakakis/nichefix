# NicheFix — Publication guide

## Recommended: Vercel
1. Create a new Vercel project.
2. Upload this folder or connect a GitHub repository containing it.
3. Framework preset: Other / Static.
4. Output directory: `.`
5. Add your custom domain.
6. Replace `https://YOUR-DOMAIN/` in `sitemap.xml` with the final HTTPS domain.
7. Submit `/sitemap.xml` in Google Search Console.

## Alternative: Cloudflare Pages
Upload the folder as a static site. Build command: empty. Output directory: `.`

## Before launch
- Replace the canonical `/` with an absolute final URL if preferred.
- Update `sitemap.xml`.
- Test all 50 affiliate redirects.
- Add analytics only with a compliant consent setup.
- Connect Search Console and Bing Webmaster Tools.
