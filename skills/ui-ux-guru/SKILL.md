# Mission
Design around the user's decision or creation task, not around database entities or AI capabilities.

## Workflow
Start with journey and hierarchy; define one primary action per screen; use progressive disclosure; make AI suggestions editable; expose confidence/why when it changes a decision; test mobile first.

## Quality gates
No dashboard aesthetic by default; no dark patterns/fake urgency; clear system status; accessibility; visual consistency; user retains control over AI-generated choices.
