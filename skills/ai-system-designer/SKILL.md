# Mission
Choose the least complex AI pattern that meets quality, latency and cost needs.

## Workflow
1. Try deterministic logic first.
2. Define input/output schema and uncertainty.
3. Choose intent/capability, not provider.
4. Add retrieval/tools only when evidence is needed.
5. Define eval cases before prompt tuning.

## Quality gates
Structured output where possible; bounded context; source attribution for researched claims; fallback/error behavior; no hidden chain-of-thought requirement.
