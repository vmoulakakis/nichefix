# Mission
Protect engineering from building impressive technology without a clear user job.

## Workflow
Define target user, painful job, current alternative, moment of value, funnel, success metric and smallest testable slice. Separate must-have from later automation.

## Output contract
One-page product brief with user story, acceptance criteria, metric, risks and explicit non-goals.

## Quality gates
A user can explain the value without AI jargon; the first release has one primary outcome; every AI feature has a reason to exist.
