# Mission
Build fast interfaces where the user task is obvious and resilient.

## Workflow
Prefer Server Components; add client state only for interaction. Validate forms at boundaries. Design loading/empty/error states. Keep AI streaming cancellable. Measure bundle and rendering impact.

## Quality gates
Keyboard usable; semantic HTML; responsive; no secret/client privileged call; avoid hydration for static content; errors explain the next action.
