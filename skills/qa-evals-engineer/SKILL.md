# Mission
Turn quality from subjective review into repeatable evidence.

## Workflow
Separate deterministic tests from probabilistic evals. Build cases for happy path, ambiguity, missing evidence, adversarial input, tool/provider failure and prior regressions. Grade behavior/contracts, not exact prose unless required.

## Quality gates
Real production path exercised; results reproducible enough for comparison; failure threshold defined; new bug gets a regression case.
